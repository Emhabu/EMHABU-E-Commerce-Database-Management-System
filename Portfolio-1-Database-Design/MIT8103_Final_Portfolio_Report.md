# MIT 8103 – ADVANCED DATABASE SYSTEMS
## Individual Practical Database Portfolio

**Academic Session:** 2026/2027  
**Semester:** First Semester  
**Project Title:** EMHABU E-Commerce Database Management System

### 1. Introduction

This project presents the design and practical implementation of a database management system for EMHABU, a simulated e-commerce business. The system manages customers, products, orders, order items, payments and deliveries.

The project demonstrates relational database design, SQL query processing, transaction management, NoSQL data modelling and distributed database concepts.

### 2. Portfolio 1: Database Design and Modelling

MySQL was used to create the `emhabu_ecommerce` database and its relational tables. The database design separates customer, product, order, order item, payment and delivery information.

Primary keys and foreign keys are used to identify records and establish relationships between tables. Normalisation principles (1NF, 2NF and 3NF) guide the organisation of the data to reduce unnecessary duplication and improve consistency.

### 3. Portfolio 2: Query Processing and Optimisation

SQL queries were prepared to retrieve customer, product and order information. JOIN operations were used to combine related records.

Query execution plans using EXPLAIN and indexing were included as optimisation activities. Performance observations should be based on the actual execution results recorded in the project evidence.

### 4. Portfolio 3: Transactions and Concurrency

Transaction management was explored using MySQL. COMMIT and ROLLBACK demonstrate how database changes can be saved or cancelled.

A ROLLBACK test restored the Laptop product price to its original value of ₦850,000. Transaction isolation and concurrency control were also considered in the implementation.

### 5. Portfolio 4: NoSQL and Advanced Data Models

MongoDB was used to create product, order and shopping cart collections. Embedded documents and queries were used to demonstrate flexible document-oriented data modelling.

Redis was used to demonstrate key-value storage through SET, GET and EXISTS operations. This provides an example of fast access to shopping cart information.

### 6. Portfolio 5: Distributed and Cloud Database Exercise

A local single-node MongoDB replica set was configured and initialised. The replica-set status was checked, and the local member was confirmed as PRIMARY.

This exercise demonstrates replica-set configuration and primary-node status. It does not demonstrate multi-server replication, automatic failover or an actual cloud deployment. Sharding, availability and consistency are discussed as distributed database concepts.

### 7. Individual Reflection

The project improved my practical understanding of relational and NoSQL databases. I gained experience creating database tables, writing SQL queries, handling transactions, working with MongoDB documents, using Redis key-value operations and configuring a MongoDB replica set.

The project also highlighted the importance of database normalisation, data consistency, performance optimisation, security and reliable database architecture.
