# EMHABU E-Commerce Database Management System

## MIT 8103 – Advanced Database Systems

**Academic Session:** 2026/2027  
**Semester:** First Semester  
**Assessment:** Individual Practical Database Portfolio

## 1. Project Overview

This project demonstrates the design and implementation of a database management system for EMHABU, a simulated e-commerce business.

The system focuses on managing customers, products, orders, order items, payments and deliveries using relational and NoSQL database technologies.

## 2. Technologies Used

- MySQL – Relational database management
- MongoDB – Document-oriented database
- Redis – In-memory key-value storage
- MongoDB Replica Set – Local distributed database exercise
- GitHub – Project version control and documentation

## 3. Portfolio Structure

- Portfolio 1: Database Design and Modelling
- Portfolio 2: Query Processing and Optimisation
- Portfolio 3: Transactions and Concurrency
- Portfolio 4: NoSQL and Advanced Data Models
- Portfolio 5: Distributed and Cloud Database Exercise
- Screenshots: Practical implementation evidence
- Final Documentation: Project report and reflection

## 4. Project Scope

The project explores relational database design, SQL query processing, transaction management, NoSQL data modelling, key-value operations and distributed database concepts.

## 5. Implementation Note

The MongoDB replica-set exercise uses a local single-node configuration. It demonstrates replica-set initialisation and PRIMARY status, but does not demonstrate multi-server replication or cloud deployment.
