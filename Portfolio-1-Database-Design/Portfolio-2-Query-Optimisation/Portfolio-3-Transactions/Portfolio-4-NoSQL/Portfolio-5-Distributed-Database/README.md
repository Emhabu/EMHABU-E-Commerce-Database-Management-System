# Portfolio 5: Distributed and Cloud Database Exercise

This folder contains the distributed database configuration and practical evidence for the EMHABU E-Commerce Database Management System.

## Contents
- MongoDB Replica Set Configuration
- Replica Set Initialisation
- Replica Set Status and PRIMARY Verification
- Replication Concepts
- Sharding Concepts
- Availability and Consistency
- Cloud Database Discussion

## Implementation Note

The practical exercise uses a local single-node MongoDB replica set. It demonstrates replica-set initialisation and PRIMARY status but does not demonstrate multi-server replication, automatic failover or cloud deployment.
